# Limitations

1. The dataset is synthetic, so the experiment cannot prove performance on real production telemetry.
2. The label is generated by an assumed risk process rather than observed incidents.
3. The prototype treats each observability window as independent and does not model long temporal sequences.
4. Distributed traces, log text, topology changes, and incident annotations are not included.
5. The improved model is selected for simplicity, not because it is guaranteed to be best for every observability setting.
6. Alert fatigue, escalation procedures, and human decision-making are outside the current scope.
7. The repository is a research implementation, not a production-grade monitoring service.

# Future work

- Test with anonymized real service metrics.
- Add rolling-window and lagged features.
- Evaluate probability calibration and threshold selection.
- Add drift detection for changing traffic patterns.
- Compare additional lightweight models such as gradient boosting.
- Study explainability outputs that are useful to operations teams.
